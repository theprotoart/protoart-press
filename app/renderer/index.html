How it works

PA-2 Operator's Card

ProtoArt Press makes images, PDFs, video and audio smaller. Drop files or whole folders anywhere on the panel, or press LOAD (⌘O). Each file goes to its module, and every result is checked before it's kept. Everything runs on your Mac; nothing is uploaded.

The modules

Each format has its own module, and they all work the same way:

  • IN (green): when lit, that module presses its files. Switch it off and those files are skipped.
  • GENTLE · BALANCED · AGGRESSIVE (amber): how hard to compress. Only one lights at a time.
  • Knob: an optional size limit. KEEP or FULL never changes the size, and nothing is ever enlarged.
  • Blue buttons: a format choice for that module.

The lamp at the top of a module glows while it's working. Double-click a knob or a quality button to reset it.

IMAGE · JPG, PNG

STRENGTH aims for no visible change: about JPEG quality 90 / 85 / 80, checked against the original with a perceptual comparison (SSIM). MAX SIZE shrinks the long edge. PNG LOSSLESS keeps every pixel; REDUCE allows a 256-color palette only when that's invisible (screenshots, icons, graphics).

PDF

Only the pictures inside are recompressed: text, fonts and drawings stay sharp and selectable. Press measures how large each picture is actually shown on the page, resizes it to the RESOLUTION you pick (150 dpi suits screens and office printing; 300 keeps print quality) and re-encodes it with the same perceptual check used for photos, never going below JPEG quality 80 / 75 / 56. Black-and-white pictures are stored as one channel. COLOR GRAY makes every picture black-and-white. Unusual PDFs are handled by macOS instead. Password-protected PDFs are left alone.

VIDEO · MP4, MOV, M4V

Re-encodes the picture with Apple's hardware encoder, with a keyframe at least every 5 seconds so seeking stays quick. Compressed sound is copied untouched; uncompressed sound becomes 160 kbps AAC. RESOLUTION scales down (4K, 1440, 1080, 720, 540). HEVC is about a third smaller; H.264 plays everywhere. Phone videos keep their orientation. HDR and copy-protected videos are left as they are for now.

AUDIO · WAV, AIFF, FLAC, MP3, M4A

AAC at 256 / 192 / 128 kbps for stereo (mono gets half), or LOSSLESS (Apple Lossless): bit-perfect and about half the size of WAV. Results are .m4a files. SAMPLE RATE can lower the rate (AAC tops out at 48 kHz). Surround files are left alone. Song tags (title, artist, artwork) aren't carried over yet.

MINIMUM SAVING

A result is only used if it's at least this much smaller (1, 3, 5 or 10%). If it isn't, the original is kept as is and the log says KEPT. It never changes quality; it just skips files that would barely shrink. Resized images and videos are always kept.

OUTPUT

  • COPY: results go into a "Pressed" folder beside the originals, which aren't touched. Files that didn't shrink are copied too, so the folder is complete.
  • REPLACE: swaps each file in place. Originals go to the Trash, so you can still get them back. Audio becomes .m4a beside where the original was.

METADATA

  • KEEP: camera, date, location and keywords all stay.
  • NO GPS (default): removes only the location from photos and videos.
  • STRIP: removes everything, including a PDF's title, author and keywords.

Color profiles always stay, and photos are stored upright, so nothing comes out sideways or with shifted colors.

Meters

  • VU: overall completion of the batch, weighted by file size. The lamp lights while it's working.
  • TIME LEFT, SAVED and REDUCTION: the batch estimate, space saved this session, and the overall percentage.
  • LEDs: POWER · ACTIVE blinks while working · DONE (blue) when a batch finishes · FAULT if a file failed.

Session log

Badges show the type: IMG PDF VID AUD. WAIT queued · % working · −xx% saved · KEPT left as is (hover for why) · FAULT couldn't be processed. Double-click a row to show the file in Finder. CLEAR empties the log; it doesn't touch any files.

Shortcuts (symlinks) inside folders are skipped, so only what you chose is touched. Images over 150 megapixels or 512 MB are left alone.

RESET

Puts every control back to its default: all modules IN, BALANCED everywhere, image FULL + REDUCE, PDF 150 dpi in color, video KEEP + HEVC, audio KEEP + AAC, 3%, COPY, NO GPS.
